Tech Stack

HTML5

HTML5 adalah versi terbaru dari HTML (HyperText Markup Language). Dirilis pada tahun 2014 dengan banyak peningkatan dan fitur baru.

CSS

CSS3 adalah versi terbaru dari CSS (Cascading Style Sheets). Dirilis secara bertahap dari 2011 hingga sekarang dengan banyak modul baru.

Python

Python adalah bahasa pemrograman tingkat tinggi (high-level programming language) yang sangat populer dan serbaguna. Python dikembangkan oleh Guido van Rossum dan pertama kali dirilis pada tahun 1991. Bahasa ini terkenal karena sintaksnya yang mudah dibaca dan dipelajari. Karakteristik Python

Bootsrap

Bootstrap adalah sebuah framework CSS (Cascading Style Sheets) populer yang digunakan untuk membangun website yang responsive dan modern .Bootstrap dikembangkan oleh Twitter dan sekarang menjadi salah satu framework frontend yang paling banyak digunakan di dunia. Fungsi Utama Bootstrap

GitHub & Figma

GitHub adalah platform berbasis cloud untuk menyimpan, mengelola, dan colaboração kode menggunakan sistem version control bernama Git. GitHub sangat populer di kalangan developer untuk proyek open source maupun privat.
